# Annotazioni capitolo 4

Questa cartella raccoglie note tecniche, dubbi, verifiche e anomalie della fonte relativi al capitolo 4. Stessa impostazione della cartella gemella del capitolo 3: i file normativi restano fedeli alla fonte e le osservazioni stanno qui, separate e collegate.

Le anomalie della fonte accertate durante una verifica di conformità si registrano in un file per scope, con una sezione per identificativo, secondo `../../../skills/conversione-normativa/references/ciclo-conversione-verifica.md` § 5:

- identificativi `AF-<scope>-<nn>` per le anomalie conservate alla lettera;
- identificativi `AF-COR-<scope>-<nn>` per i refusi tipografici corretti, che nel file normativo lasciano una nota di trascrizione visibile e cercabile.

Ogni identificativo `AF-COR` presente in un file normativo deve avere qui la sua sezione: una nota senza registrazione, o una registrazione senza nota, valgono come errore di conversione.
